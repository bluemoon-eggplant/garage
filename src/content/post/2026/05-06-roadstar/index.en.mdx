## Background

Planning to do an engine overhaul and full repaint going forward, so I wanted to measure the baseline condition before the restoration.

## Procedure

| no | Task | Difficulty | Notes |
|----|------|------------|-------|
| 1 | Remove plug cords | <Difficulty level={2} /> | Hard to pull out |
| 2 | Remove spark plugs | <Difficulty level={1} /> | |
| 3 | Disconnect ignition switch coupler | <Difficulty level={1} /> | |
| 4 | Install compression tester in plug hole | <Difficulty level={1} /> | |
| 5 | Crank and measure | <Difficulty level={1} /> | |

## Reflections

The compression tester I bought was the screw-in type, and I wasn't sure how tight to thread it in.
Then again, there are push-and-hold types that are pretty rough, so it's probably fine to be approximate.

## Results

Someone once said compression doesn't matter as long as the engine runs and drives fine.
Looking forward to seeing improvement after the overhaul.

### Overall compression is low

Workshop manual spec: 13.5 bar (lower limit 9.5).
Measured approximately 12–12.5 bar — low overall.
After 300,000 km with (probably) no overhaul, this is expected.

### Cylinder-to-cylinder variation is within spec

Workshop manual spec: within 2 bar.
No issues here.
